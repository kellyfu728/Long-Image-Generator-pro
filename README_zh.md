# 📄 长图生成器 Pro

🌐 语言：**简体中文** | [English](README.md)

一个基于浏览器的富文本长图生成工具。

无需安装任何软件，打开网页即可编辑、排版并导出高清长图。

项目 URL: https://kellyfu728.github.io/Long-Image-Generator-pro/

---

## 项目介绍

长图生成器 Pro 是我基于个人实际需求开发的一个小工具。

最初，它主要用于分享同人文、整理学习笔记等长文本内容。随着不断完善，它逐渐发展为一个支持富文本编辑、灵活排版以及高清长图导出的浏览器工具。

我希望它能够提供一个简单、轻量、无需安装软件的解决方案，让用户能够更加方便地编辑和分享长文本内容。

## 功能特点

- 富文本编辑
- 支持导入 TXT / DOCX（DOCX 可保留受支持的 Word 格式）
- Word 风格排版
- 左对齐 / 居中 / 右对齐 / 两端对齐
- 自定义字体
- 自定义字号
- 行距调整
- 段落间距调整
- 自定义文字颜色
- 多种背景颜色
- 自定义背景颜色
- 默认自动高度，完整导出文章
- 可选固定高度，并在内容超出时显示裁切提示
- 实时预览
- 生成后保存当前内容与排版，再进行下载
- 高清 PNG 导出
- 移动端编辑 / 预览切换与紧凑横滑工具栏
- 中英文双语界面

## 使用方法

1. 下载项目。

2. 双击打开

```
index.html
```

3. 编辑文本内容。

4. 点击 **生成长图**，保存当前内容与排版。

5. 点击 **下载 PNG** 即可导出图片。

画布默认使用自动高度，会完整导出文章。在排版设置中可以切换为固定高度；内容超出时，预览区会显示裁切线。
